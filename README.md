# Project L.O.V.E.

**Location Operations & Virtualized Edge**

Project L.O.V.E. is an AWS edge-to-cloud operations lab that simulates a Linux edge device deployed at a remote physical location.

## Goals

- Generate edge-device telemetry on Linux
- Connect the device securely to AWS IoT Core
- Monitor device health and logs
- Store operational data
- Provision cloud resources with Terraform
- Practice troubleshooting edge and cloud incidents

Device: LOVE-EDGE-01  
Location: NY-001
